# Site maintenance

This repository hosts Rickie Reilly's public website with GitHub Pages.
Read `.agents/skills/update-site/SKILL.md` before changing the website.

The publishing source is `main`, directory `/docs`. A push to main publishes.
Only files in `docs/` are website assets. Keep credentials and scratch files out.
The SpaceX model is `docs/spacex/index.html`; preserve its calculation logic and
assumptions unless the user asks to change them. Do not invent financial inputs.
Keep the `/home/` and `/spacex-5-10-year-model/` redirects working.
Domain changes are a separate operation from content updates.
